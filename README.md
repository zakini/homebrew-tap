# Zakini Tap

## How do I install these formulae?

`brew install zakini/tap/<formula>`

Or `brew tap zakini/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "zakini/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
